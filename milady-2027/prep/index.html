Parcours de préparation

Huit modules, du niveau licence 1 au niveau M2 recherche

Ce parcours mène d’un niveau de licence 1 (analyse, algèbre linéaire, un peu de programmation) au niveau requis pour commencer le stage MilaDy : lire un article sur les modèles génératifs sous contraintes physiques, écrire et entraîner un modèle de flow matching conditionnel, et juger un champ MHD généré avec des critères physiques. Il compte huit modules, environ 215 heures de travail et 121 exercices corrigés.

À propos Ces modules sont des notes indépendantes. Ils ne sont pas un cours officiel de l’ENPC, du LISN ou de l’Université Paris-Saclay. Chaque module donne ses sources ; les faits sur la recherche récente viennent de bases de faits vérifiées (dossier specs/sources/ du dépôt).

Dans quel ordre

Les modules 1 à 3 forment la branche physique, les modules 5 à 8 la branche apprentissage ; le module 4 relie les deux, car il explique pourquoi un état turbulent stationnaire est décrit par une loi de probabilité invariante.

  • Physique : 1 → 2 → 3. Le module 3 utilise les potentiels et la projection du module 1, et les bilans d’énergie du module 2.
  • Pont : 4, après 2 et 5. Il sert pour les renversements (module 3) et pour les contraintes en loi (module 8).
  • Apprentissage : 5 → 6 → 7 → 8. Le module 7 suppose la mesure image et l’équation de continuité du module 5 ; le module 8 suppose tous les autres.

Un ordre de lecture linéaire qui respecte ces dépendances est 1, 2, 5, 3, 4, 6, 7, 8.

Comment travailler un module

Chaque module suit la même structure : objectifs, prérequis, plan de travail (séances, durées, niveaux de 1 à 3 qui ne redescendent jamais), chapitres avec définitions, théorèmes et démonstrations, code Python exécuté, exercices gradués ★ / ★★ / ★★★ avec solutions, lien avec le stage, lectures pour aller plus loin et sources.

  • Lisez un chapitre, puis faites les exercices indiqués dans son plan de travail, avant de lire la solution.
  • Exécutez chaque bloc de code et modifiez un paramètre : tous les blocs tournent en moins de 30 secondes sur un ordinateur portable.
  • Gardez une page de formules par module ; le module 8 suppose que vous savez les retrouver vite.
  • Les schémas interactifs illustrent cinq notions clés : flow matching, projection de Leray, contrainte en loi, renversements et dynamo ABC.
